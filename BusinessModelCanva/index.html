Este Business Model Canvas representa el modelo de valor, usuarios, recursos, actividades, socios, costos, canales y posibilidades de crecimiento de una plataforma cultural de videojuegos cuyo producto semilla es Xicotepec bajo la niebla.

El proyecto combina desarrollo de videojuegos, tecnologías web, aplicaciones móviles y contenido cultural para ofrecer experiencias interactivas inspiradas en lugares y elementos culturales de México.

Leer el contexto completo

Xicotepec bajo la niebla funciona como el primer producto del ecosistema y permite validar las mecánicas de juego, la experiencia de usuario y la integración entre Unity, una API, una PWA y una aplicación móvil desarrollada con Flutter.

A partir de esta base, la plataforma podrá evolucionar hacia nuevas historias, nuevos Pueblos Mágicos, herramientas para creadores y un ecosistema de contenido generado por usuarios.

1. Producto semilla

Xicotepec bajo la niebla

Videojuego de acción y plataformas en 2D ambientado en una representación ficticia de Xicotepec de Juárez, Puebla. Es el primer producto para validar el concepto.

2. Unity + C#

Desarrollo del videojuego

Unity y C# permiten construir movimiento, combate, niveles y habilidades. No se afirman métricas ni funcionalidades terminadas.

3. Experiencia jugable

Explorar, combatir y resolver

Balam, Rayo y Kiro son estudiantes ficticios con habilidades diferentes. Sus habilidades permiten avanzar, enfrentar enemigos y superar obstáculos.

4. Registro de partida

Conservar la experiencia personal

Se contempla relacionar partidas, progreso y uso de personajes con la misma cuenta del jugador para su consulta posterior.

5. API

Relacionar las aplicaciones

La API conecta el videojuego y las aplicaciones de consulta con los datos de la cuenta. Es un recurso del proyecto en desarrollo.

6. Nube y base de datos

Persistir y consultar datos

La base de datos y los servicios en la nube permiten almacenar y recuperar información de partidas y estadísticas.

7. PWA + Flutter

Dos propósitos complementarios

La PWA ofrece contenido público: lugares, cultura, personajes y ranking. Flutter consulta información personal: historial, partidas, progreso, estadísticas y cuenta.

8. Información + estadísticas

Ampliar la experiencia

La consulta cultural complementa la exploración; los datos personales permiten revisar el progreso. La misma cuenta vincula la información del jugador.

Desarrollar el producto semilla de acción y plataformas 2D, con escenarios inspirados en Xicotepec y personajes ficticios. Es la base para comprobar el concepto.

2. Validación de mecánicas

Actual / en desarrollo

Probar movimiento, combate, habilidades, obstáculos y niveles. Ajustar según los problemas observados; no se presentan resultados de pruebas que no se han aportado.

3. Validación con usuarios

Actual / en desarrollo

Organizar pruebas y recoger comentarios reales sobre usabilidad, narrativa y jugabilidad. Registrar hallazgos y correcciones; no inventar entrevistas ni métricas.

4. Integración multiplataforma

Actual / en desarrollo

Relacionar Unity, API, base de datos, PWA y Flutter mediante una misma cuenta. Verificar consistencia de partidas, estadísticas, ranking e información de cuenta.

5. Nuevas historias

Crecimiento futuro

Crear nuevas campañas después de validar la experiencia inicial. Cada historia debe diferenciar su ficción de las referencias culturales que la inspiran.

6. Nuevos Pueblos Mágicos

Crecimiento futuro

Ampliar el alcance a otros lugares mediante investigación, referencias revisadas y contextualización. No existe un catálogo adicional terminado acreditado.

7. Herramientas para creadores

Crecimiento futuro

Construir un editor de niveles y herramientas Low-Code / No-Code para escenarios, historias y comportamientos. No están implementadas en el producto actual.

8. Comunidad

Crecimiento futuro

Desarrollar espacios de participación y contenido generado por usuarios. La expansión contempla reglas de convivencia, licencias, revisión y moderación.

9. Marketplace

Crecimiento futuro

Habilitar eventualmente la oferta de mapas, historias, recursos y paquetes. Requiere condiciones de publicación y operación; no hay ventas ni comisiones activas declaradas.

10. Ecosistema cultural de videojuegos

Crecimiento futuro

Integrar juegos, creadores e instituciones en una plataforma sostenible. La expansión depende de validación, recursos y acuerdos futuros; no representa contratos existentes.
