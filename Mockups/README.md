# Mockups de la aplicación Flutter

Los mockups de **Xicotepec bajo la niebla** presentan una propuesta visual de alta fidelidad para la aplicación móvil desarrollada con Flutter. Su objetivo es mostrar cómo el usuario puede acceder a su cuenta, consultar sus partidas y revisar su progreso dentro del ecosistema del proyecto.

La muestra incluye un recorrido navegable de siete pantallas:

- Splash de Lumbre Studio.
- Pantalla de progreso y carga.
- Inicio de sesión.
- Creación de cuenta.
- Inicio con resumen de actividad.
- Historial de partidas.
- Detalle de una partida, con duración, puntuación, derrotas y tiempo utilizado por personaje.

El flujo principal va desde la presentación de la aplicación hasta la consulta detallada del tutorial UTXJ. Los mockups conservan la identidad visual del proyecto mediante tonos verdes, superficies claras, detalles dorados y elementos cobrizos. También incorporan estados, botones, formularios, navegación inferior y acciones de transición para representar la experiencia esperada sin sustituir la implementación funcional de la aplicación.
